## 🚀 About the Portfolio

This portfolio is built entirely from scratch with **Flutter Web**, delivering a responsive, high-performance, and animated modern web experience:
- **Responsive Layout:** Pixel-perfect adaptive UI across Mobile, Tablet, and Desktop screens.
- **Glassmorphic Design:** Modern glass cards, custom gradients, and fluid typography.
- **Micro-Animations:** Powered by `flutter_animate` for smooth transitions and interactions.
- **Live Filtering & Search:** Category filter chips and search bar across featured production apps.
- **Clean Architecture:** Modular feature-based structure with GetX state management.

## 💻 Getting Started

To run this portfolio project locally:

### Prerequisites
- Flutter SDK (v3.19 or higher)
- Dart SDK (v3.3 or higher)
- Chrome or modern web browser

### Installation
```bash
# Clone repository
git clone https://github.com/23amitkumar/amit_portfolio.git
cd amit_portfolio

# Install dependencies
flutter pub get

# Run on Chrome
flutter run -d chrome

# Build for Web production
flutter build web --release --base-href "/amit_portfolio/"
```
